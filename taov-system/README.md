# תאוב — מערכת עסקית מקומית

יישום חדש לפי רשימת הדרישות הזמינה בשיחה. אינו שחזור של קוד אבוד. אתר אבירית המקורי נשמר ללא שינוי. כל נתוני ההדגמה והבדיקות סינתטיים; אין להכניס מידע אישי אמיתי בשלב זה.

## Windows — הורדה והפעלה

1. התקינו Node.js 24 LTS מהאתר הרשמי https://nodejs.org (כולל npm).
2. ב־GitHub פתחו את הענף `taov-system`, בחרו **Code → Download ZIP**, חלצו את כל הקבצים. אפשר במקום זאת: `git clone --branch taov-system https://github.com/dudid464/dudid.git`.
3. פתחו PowerShell בתיקיית `taov-system` שבתוך המאגר שהורד.
4. הריצו:

```powershell
npm install
npm test
npm start
```

5. פתחו בדפדפן `http://127.0.0.1:3000`. משתמש: `admin`. בהפעלה ראשונה השרת מדפיס סיסמה אקראית; שמרו אותה במנהל סיסמאות. היא אינה נשמרת ב־Git. ניתן לבחור סיסמה לפני ההפעלה הראשונה בלבד:

```powershell
$env:ADMIN_PASSWORD = Read-Host 'Initial admin password'
npm start
```

הנתונים נשמרים ב־`data/taov.sqlite` גם אחרי עצירת השרת. התחברויות דורשות כניסה מחדש אחרי הפעלה. עצירה: Ctrl+C. אין למחוק את `data`. גיבוי הקוד ב־Git אינו מגבה את הנתונים. בזמן שהשרת עצור ניתן להעתיק את כל תיקיית data למקום מאובטח; היא מכילה מידע וחשבונות ללא הצפנת דיסק.

## יכולות

- לידים, משפחות, עובדים, התאמות, תיקים ומשימות: יצירה, עריכה, מצב, אחראי ומועד יעד.
- קישור רשומות באמצעות מזהי משפחה, עובד ותיק; אימות קיום בשרת.
- הצעות התאמה לפי חיתוך כישורים מופרדים בפסיקים, עם ציון והסבר. נדרש שיקול דעת אנושי; אין החלטה אוטומטית.
- מסמכים: רשומה ומצורף עד 400KB, הורדה כקובץ ללא הרצת תוכן.
- בקרה בכל דקה כאשר השרת פועל, או בלחיצה: יוצרת התראה מדומה על איחור בתיק/משימה, בלי כפילות של התראה פתוחה. אין מנגנון לשליחת WhatsApp, גם אם מוזנים פרטי חיבור.
- דוח JSON, ייצוא רשומות CSV, היסטוריית פעולות, תפקידי מנהל/עורך/צופה. הרשאות כלל־מערכתיות ולא לפי תיק. מנהל יוצר משתמשים; אין שחזור סיסמה בדוא״ל.
- עוזר מקומי מבוסס כללים: חיפוש מילולי, סוג רשומה, ״פתוחות״ ו״באיחור״. אינו מודל AI ואין הבנה חופשית מלאה.
- גיבוי AES-256-GCM עם מפתח הנגזר ב־scrypt מסיסמה נפרדת; הורדה ושחזור במיזוג שאינו דורס מזהים קיימים. הגיבוי כולל רשומות והעתק היסטוריה; השחזור ממזג רשומות בלבד. חשבונות אינם כלולים. שכחת סיסמת הגיבוי אינה ניתנת לשחזור. אין גיבוי מתוזמן אוטומטי.

## Google Sheets — קריאה בלבד

השרת תומך בבקשת GET ל־Google Sheets API בלבד; אין כתיבה או סנכרון דו־כיווני. יש לספק משתנה שרת `GOOGLE_ACCESS_TOKEN` בעל scope ‏`https://www.googleapis.com/auth/spreadsheets.readonly` וגישה לגיליון הסינתטי הנבחר. האסימון אינו נשלח לדפדפן, אינו נשמר במסד ואינו נכלל בגיבויים. כרגע אין מסך OAuth או רענון אסימון; נדרשים חיבור ואישור נפרדים, וגם הרשאת רשת ל־sheets.googleapis.com בסביבת ענן. אין להכניס אסימון לקוד או ל־Git. הקריאה החיה לא נבדקה מול Google; בדיקות המערכת אינן פונות לשירות חיצוני.

## הפעלה ובטיחות

Node.js 24 ומעלה נדרש (SQLite מובנה). אין תלויות npm חיצוניות. `npm test` מפעיל בדיקות HTTP עם מסדים זמניים. `npm run check` בודק תחביר שרת.

ברירת המחדל: localhost בלבד, HTTP מקומי, cookie מסוג HttpOnly/SameSite, סיסמאות scrypt, הגבלת ניסיונות כניסה, מגבלת בקשות, CSP. לא לפרסם את השרת ישירות באינטרנט. לשימוש מרוחק נדרשים TLS, `COOKIE_SECURE=1`, ניהול סודות, גיבויים, מדיניות הרשאות ואישור פריסה נפרד. SQLite אינו מוצפן על הדיסק. משתמשים מסוג viewer קוראים את כלל הנתונים; editor יכול לשנות רשומות; admin מנהל משתמשים וגיבויים. אין מחיקת רשומות כדי למנוע אובדן בטעות; סמנו כהושלם. אין מחיקת משתמשים או שינוי סיסמה בממשק בגרסה זו.

## שמירת הקוד

הפיתוח נשמר בענף `taov-system`, ללא שינוי main. אחרי שינוי:

```powershell
git add taov-system
git commit -m "Describe your change"
git push origin taov-system
```

בקובץ ZIP יש קוד בלבד, לא נתוני עבודה או סיסמת מנהל. שמרו גיבוי נתונים מוצפן בנפרד.
